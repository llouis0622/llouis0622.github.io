안전벨트 제조 · 조립 공정의 융합데이터를 수집하고 실증하는 다년도 국가 과제에 참여하게 됐다. 담당 기술 범위는 **PINN · Physical AI Agent · 제조 시계열 데이터 · 모델 검증 · OT 연계**다. 과제의 개념과 1차년도에 할 일을 정리한다. (참여 기관 · 세부 사양은 제외했다.)

<!--more-->

## 핵심 개념

| 개념 | 역할 |
|---|---|
| **PINN** | 공정별 물리 법칙과 실측 데이터를 결합해 품질을 예측하고 물리 원인을 규정 |
| **World Model** | 현재 공정 · 설비 상태와 조치 조건에 따른 미래 품질 · 설비 · 생산 상태 예측 |
| **PI-LAM** | PINN · World Model 결과를 공정 조건 변경, 설비 점검, 정비 같은 실행 가능한 Action으로 변환 |
| **Physical AI Agent** | 데이터 수집 → 추론 → 조치 추천 → 작업자 승인 → 설비 반영 → 결과 환류를 통합 |
| **Action Data** | 조건 변경 · 승인 · 보류 · 정비 · 재작업과 그 결과를 State–Action–Result–Reward로 표현 |
| **Digital Twin** | 조치 후보의 품질 · 설비 부하 · Cycle Time 영향을 실공정 적용 전에 검증 |

이 모든 것이 **Physical AI 폐루프**로 묶인다. 데이터 수집 → 품질 예측 · 원인 규정 → 조치 추천 → 사전 검증 → 작업자 승인 → 설비 실행 → 결과 검증 · 재학습.

## 공정별로 다루는 물리

- 파이프 보더링: 압력 · 하중 · 변위 · 속도 · 금형 상태 → 보더링 높이 · GAP 예측과 조건 보정
- 베이스락 압입: Force–Distance 곡선 → 미압입 · 과압입 · 편심 · 걸림 탐지
- 스크류 체결: Torque–Angle 곡선 → 미체결 · 과체결 · 헛돎 · 풀림 위험
- 텅 레이저 각인: 출력 · 스캔 속도 · 포커스 · 온도 → 각인 깊이 · OCR Score
- AI Robot: 3D Vision · 관절 토크 · F/T · 파지력 → 파지 실패 · 낙하 위험

PINN이 재미있는 지점은 여기다. 소성 변형, 접촉 역학, 체결 토크 역학, 열전도 같은 **지배 물리 현상과 입력 · 출력 · 경계 조건을 먼저 정의**해야 모델이 성립한다. 데이터만 많다고 되는 문제가 아니다.

## 1차년도에 하는 일

- 13개 실증 공정의 CTQ · 불량 모드 · 물리 변수 · 제어 변수 정의
- 제품 ID · LOT · 설비 · Recipe · Cycle · 시각 기반 **데이터 동기화 구조** 설계
- 우선 공정(보더링 · 레이저 각인) 고해상도 물리 데이터 수집 기반 구축
- Manufacturing Context 스키마와 Action Dataset(State–Action–Result–Reward) 구조 설계
- Physical AI Agent 요구사항 정의, Apply · Hold · Fallback · Interlock · Rollback 안전 조건 수립
- PINN 기초 모델 공동 설계서

## 지난 과제에서 배운 것을 적용한다

8월에 제조 AI 사업을 준비하며 배운 것(진동 원파형 없으면 결함 분류 불가, 라이선스 먼저, GPU 예산은 여유로 본다)이 그대로 쓰인다. 이번에는 센서 측정 범위 · 정확도 · 분해능 · 샘플링 주기 · 설치 위치를 **설계 단계에서** 정한다. 데이터 신뢰성 검증(캘리브레이션, 결측 · 노이즈 · 통신 지연)도 1차년도 산출물에 들어 있다.

PINN과 Physical AI Agent는 이론으로만 알던 영역이다. 공부할 게 많다.
