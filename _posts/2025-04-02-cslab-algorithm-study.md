경성대 CSLab 부원들과 알고리즘 · 코딩테스트 스터디를 시작했다. 목적은 두 가지다. 매주 꾸준히 문제를 풀게 만드는 것, 그리고 **GitHub 협업 흐름(fork · PR · 리뷰)을 몸에 익히는 것**.

<!--more-->

## 운영 방식

1. 스터디 저장소를 fork 한다.
2. 자신의 이름 또는 GitHub ID로 폴더를 만들고, 알고리즘 분류별로 소스 코드를 올린다.
3. 커밋 규칙을 지켜 올린다. `[BOJ] 문제이름 / 난이도`, `[PG] ...`, `[LTC] ...`, `[CFS] ...`
4. 매주 2문제 이상 원본 저장소로 PR 한다. 제목은 `이름 / 알고리즘_분류 / 몇 문제`.
5. 다른 사람의 PR을 보고 자유롭게 코드 리뷰한다.

PR 코멘트에는 이번 주 문제의 알고리즘 분류, 어려웠던 문제, 막힌 지점을 적도록 했다. 리뷰어가 무엇을 봐야 할지 바로 알 수 있고, 본인도 회고가 된다.

## 코드 리뷰 규칙

- 전체 코드 흐름을 먼저 파악하고, 푼 사람이 어떻게 풀었는지 이해한다.
- 잘한 점, 더 좋은 코드나 고칠 부분, 왜 이렇게 풀었는지 궁금한 점, 다른 풀이 방법을 남긴다.

리뷰가 "정답 지적"이 아니라 "다른 풀이 제시"가 되도록 하는 게 핵심이었다.

## 강의 자료: Algorithm Deep Dive

스터디와 함께 프로그래머스 기준으로 20개 챕터의 자료를 만들어 나가고 있다.

기초 코드 작성 → 수학 → 배열/연결 리스트 → 문자열 → 정렬 → 스택/큐/덱 → 해시 → 완전탐색/재귀/시뮬레이션 → 백트래킹 → 그리디 → BFS/DFS → 이분탐색/투 포인터 → DP → DP Advanced → 우선순위 큐 → 트리/BST → 그래프/위상정렬 → Union-Find/MST → 플로이드/다익스트라 → KMP/Trie

챕터마다 발표 슬라이드와 대표 문제(예: DP 챕터의 2×n 타일링 · 정수 삼각형 · 도둑질 · 스티커 모으기)를 붙였다. 자료는 [Algorithm_Deep_Dive](https://github.com/llouis0622/Algorithm_Deep_Dive), 스터디 규칙은 [algorithm_study_for_ksu_cslab](https://github.com/llouis0622/algorithm_study_for_ksu_cslab)에 있다.
